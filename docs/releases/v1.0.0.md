# Release v1.0.0: notes and how to cut it

Prepared ahead of the 12:20 UTC freeze on 19 Nov 2026. The tag is **not** created yet. Timeline, owners and rollback: [freeze.md](freeze.md).

## How to cut it (at the freeze)

1. Fold anything under "Unreleased" in `CHANGELOG.md` into the 1.0.0 section; merge that PR; wait for `main` to be green and Vercel to report the deploy.
2. Tag the exact commit that is live:
   ```bash
   git fetch origin && git tag -a v1.0.0 origin/main -m "v1.0.0: Watad challenge procurement platform"
   git push origin v1.0.0
   ```
3. Create the GitHub release from the tag with the body below:
   ```bash
   gh release create v1.0.0 --repo malikmmoaz/watad-challenge --title "v1.0.0" --notes-file docs/releases/v1.0.0-notes.md --verify-tag
   ```
